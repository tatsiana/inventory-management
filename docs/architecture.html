Factory Inventory Management System

A demo of a two-tier app. A Vue 3 single-page app talks to a FastAPI service, which serves mock data from JSON files held in memory. There is no database, no authentication, and no persistence.

System architecture

Three layers. Requests go left to right, and JSON responses come back the same way.

Data flow: changing a filter

Here is what happens when a user picks a warehouse on the Dashboard.

  1. User changes a filter in FilterBarThis updates one of four module-level refs in useFilters.js: period, location, category or status. The refs are singletons, so every view shares the same state.
  2. The view's watcher firesDashboard.vue watches all four refs and calls getCurrentFilters(), which maps location to warehouse and period to month.
  3. api.js sends parallel requestsIt runs Promise.all over summary, orders, inventory and backlog. Any value set to 'all' is left out of the query string.
  4. FastAPI filters in memoryapply_filters() uses list comprehensions to match warehouse, category and status, case-insensitively for the last two. filter_by_month() does a substring match on order_date, and expands Q1–Q4 2025 into their three months.
  5. Aggregate and validateThe summary endpoint calculates inventory value, low-stock count and pending orders on each request. Pydantic response_models validate the list endpoints.
  6. Reactive renderResponses land in refs such as allOrders and inventoryItems. Computed properties derive the KPIs and chart series, and the SVG charts re-render.

Observations

Things worth knowing before you change anything.

  • The server never writes data. The JSON files are loaded once at startup and only read after that, so a restart resets everything.
  • The frontend calls endpoints the backend doesn't have. The tasks calls in App.vue and the purchase-order helpers in api.js point at routes that don't exist in main.py, so those calls will return 404.
  • Backlog.vue isn't routed. The view exists but isn't registered in main.js. Backlog data reaches the UI only through the Dashboard and BacklogDetailModal.
  • Inventory ignores the time filter. Inventory has no time dimension, so the summary's inventory value and low-stock count don't change with the period filter.
  • The backlog count ignores all filters. total_backlog_items in the summary is always the full count.
  • The API URL is hard-coded. http://localhost:8001 appears in api.js and Reports.vue. There's no Vite proxy or environment variable.
  • CORS accepts any origin. That's fine for a local demo but not for anything deployed.
  • Currency conversion is display-only. JPY values use a fixed rate of 150 in utils/currency.js.
